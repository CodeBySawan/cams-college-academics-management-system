# College Academics Management System (CAMS)

CAMS is a college academic management application being developed using Java, Spring Boot, and MySQL. The goal is to manage student records and academic activities through a centralized system.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Git and GitHub

## Planned Modules

- Student management
- Course management and enrollment
- Attendance management
- Academic results and marks
- Role-based access for administrators, faculty, HODs, and students

These modules represent the planned scope and are not necessarily implemented yet.

## Project Status

Initial project setup completed. Database integration, application features, and testing will be developed incrementally.
